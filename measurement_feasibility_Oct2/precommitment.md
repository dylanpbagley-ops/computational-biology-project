# Option 1 exploratory feasibility protocol

Written before numerical outcome comparisons on October 2, 2026. Existing cohort has been studied previously; this is discovery, not prospective validation. Scope is healthy-cell measurement and annotation recovery only.

Access checks: verify published feature order against cache, metadata and barcode order, matrix dimensions, finite nonnegative values, and sampled raw coordinates. Labels are multimodal WNN-derived and therefore not independent of protein inputs. No clinical or physical sorting claims.

Primary task: DC versus all other annotated cells, excluding Doublet (level 2) and broad other group. Secondary easy reference: B versus same background. Use all times for each donor together. Eight rotations: held-out test donor; next donor cyclically is calibration; remaining six are training. No test/calibration labels for feature selection or fitting. Final calibration uses negative-cell 99th percentile with strict greater-than calls, targeting 1% false-positive rate (NOT 1% contamination).

Compare feature selection by absolute standardized mean difference, mean donor AUC separation, and worst donor AUC separation. Direction set from training class means. Exclude antibody controls. Select top 1, 2, 4 features per method. All use the same ridge logistic model, log1p counts, training-only standardization, fixed regularization. No normalization using unmeasured markers. Train on uniform donor subsamples of 250 and 1000 cells; preserve natural class proportions, but increase to include up to 50 positives if necessary using all available positives when fewer. Weight adjustment for class sampling retains donor class proportions. Test on all eligible held-out cells. Feature selection uses training samples only.

Report per-donor recall, false-positive rate, precision, average precision if available, feature selections and sample counts. No p-values treating cells as independent donors. Primary contrast: worst-donor selection versus mean-effect selection, 4 features, 1000 training cells/donor. Screening threshold: >=5 percentage point median recall gain, positive gain in >=6/8 donors, and FPR <=1.5% in >=6/8 donors, without more FPR violations than baseline. This is a practical screening criterion, not an established effect size or significance test. Also compare donor-mean AUC selection; a proposed advantage must not be explained simply by standard distribution-based feature ranking.

If the simple robust approach fails this screen, conclude only that this specific candidate has not earned further development; do not infer no possible method can work. If it passes, stronger method competitors and independent labeling/cohort are still required. No searching alternative endpoints or tuning cutoffs in this pilot. Move to option 2 feasibility if this candidate does not earn commitment. Save protocol hash before execution; changes require explicit addendum.
