# Option 2 access and sampling pilot

October 2, 2026, before outcome inspection of selected wells. This is a feasibility test of measurement reliability, not a treatment-efficacy study. Initial JUMP backend CSV was confirmed to be well-averaged and rejected for the distribution question. Per-site Nuclei.csv files provide individual-object measurements; only their schema has been inspected so far.

Use cpg0000-jump-pilot, batch 2020_11_04_CPJUMP1, two U2OS plates BR00117011 and BR00117012 (same recorded condition, no recorded anomaly). Select six distinct nonempty broad_sample IDs and six solvent-only wells from official plate map using seed 20261002, after sorting well positions; for each selected compound ID use its lexicographically first well. Same wells on both plates. Retrieve sites 1-9. No selection by observed phenotype. Prespecified nuclear features: area, eccentricity, solidity, mean DNA/AGP/ER/Mito/RNA intensity. Features describe measured objects; image segmentation validity is not independently established.

Access gate: correct numeric schema, finite selected measurements, all expected sites, unique object IDs within image, and resolvable well/condition/plate identifiers. Source file URL, SHA256, bytes and retrieval time retained; reduced numerical extracts retained. This subset is not representative of all compounds and contains only two same-batch plates.

Numerical pilot: compare mean profiles with profiles made of the 10th, 50th and 90th percentiles per feature. Scale features by plate-1 pooled control-cell interquartile range (floor 1e-6), separately center each plate on its control reference for distance-to-control calculations. Report distance-to-control (mean absolute coordinate difference) for full nine sites, and 30 random three-site subsets per well/plate. Quantify relative subsampling error using the root-mean-square full-distance scale over wells (avoid unstable near-zero denominators). Compare with uniform random-cell subsets of matched cell count. Random-cell sampling is an explicitly optimistic computational comparator, not a feasible independent acquisition plan. Compare plate-to-plate Spearman ranking of full-distance scores descriptively; no cell-level p-values.

This pilot's success gate is technical: matched cell/site/replicate data can be loaded, and sampling errors can be measured. A 20% excess of median three-site error over matched random-cell error is a prespecified flag that field structure deserves further investigation, not a required positive result. Mean profiles are a baseline, not the only state of the art. Quantile summaries are a simple existing distribution representation, not a novel algorithm. No adaptive stopping or minority-response detector is claimed as validated here. Full feasibility report must separate data feasibility, evidence of a measurement problem, novelty, and demonstrated method advantage. If technically feasible, retain option 2 for a larger locked benchmark rather than calling it a failed field or advancing to wet-lab dependencies.
