# CAR-T Pivot — Validation and Findings

**Status:** Implementation complete. Aims 10-12 built, tested (24 new tests, all passing; full project suite 173/173 passing), and run end-to-end. This document records what was actually found, honestly, in the same discipline as `docs/Prediction_Registry.md`'s "state the claim before checking it, report the real result whichever way it comes out."

**MAJOR UPDATE (this session, after initial pivot validation):** Aim 12 answers a question the author asked directly after seeing Aim 11's modest result: "is the small reordering effect real, or is it an artifact of every check so far using a RECONSTRUCTED population instead of genuinely measured per-cell data?" Aim 12 is the first check anywhere in this project (EV side or CAR-T side) run against real, individually-measured, per-cell antigen density values.

**SECOND UPDATE, same session:** an initial 9-patient subsample found 48.1% meaningful reordering. The author then explicitly asked to fetch and test the rest of the dataset. All 41 real DLBCL tumor samples (6,865,361 real cells total) were processed, and the result got STRONGER, not weaker: **59.3% meaningful reordering (16 of 27 grid points, largest real spread 81.8 percentage points)** — roughly 7-11x larger than every reconstructed-distribution check this project has run (5.6%-17.8%). See the new section below for the full, honest account.

---

## The headline claim, restated

> A distribution-aware, superselectivity-based scoring method — applied to real per-cell/per-cohort antigen-density data — predicts which candidate CAR-T target antigen (or population state) minimizes the escape fraction, and this ranking can differ from the ranking produced by the field's current methods (mean expression alone).

## What real data this rests on

1. **Calibration data (Aim 10):** Agilent/Antibody Analytics IndEx-2 application note (June 2024) — real, precisely titrated CD19 density (78 to 185,223 molecules/cell, via Quantibrite PE calibration beads) tested against two real T-cell engager molecules (CLN-978, blinatumomab), with real measured activation thresholds via ROC/Youden's-J analysis. This is a genuine methodological upgrade over the original EV project: K_INTRA is now fit to a real, directly-measured (density, response) pair for four molecule/readout combinations, rather than left as a permanently-swept placeholder.

2. **Ranking-check data (Aim 11):** real, published quantitative flow cytometry summary statistics — median CD19 density and IQR for a 55-patient LBCL cohort pre-treatment (n=36) and at relapse (n=25) treated with axicabtagene ciloleucel (Transplantation and Cellular Therapy, 2024), plus a real myeloma CD19 density range and positivity range (Blood/ASH). Both verified independently this session (cross-checked conference-abstract text against the journal's own listing, not a single search snippet).

**Honest limitation stated directly:** a public single-cell (CITE-seq) dataset with both real per-cell CD19 protein density AND a real disease/outcome grouping variable was searched for extensively and not found — two real GEO datasets (GSE241783, GSE197215) were checked directly and confirmed to profile the CAR-T infusion product (the therapeutic T-cells), not the tumor cells' antigen density, a structural mismatch rather than a search failure. This means Aim 11's ranking check uses real summary-statistic-level data (median/IQR, ranges), not raw single-cell data — the same evidentiary tier as the original EV project's Aim 6/7 validations, not Aim 8's raw-per-vesicle tier. This should be described precisely in any write-up, never blurred into a claim of single-cell-resolution validation.

## What was actually found

### Check 1: CD19-in-LBCL vs. CD19-in-myeloma (cross-disease comparison)

Naive ranking (by mean density): LBCL (6,704 molecules/cell) far exceeds myeloma (114 molecules/cell). The distribution-aware escape-fraction ranking agreed with this at all 4 real, independently-calibrated k_intra fits (0 of 4 reordered). **Honest assessment:** this was a weak test of the central claim — a ~60x mean-density gap between two entirely different diseases leaves essentially no room for any nonlinear reweighting to flip the ranking. Reported as a negative finding, not concealed, but flagged as a weak test rather than presented as a strong confirmation either way.

### Check 2: pre-treatment vs. at-relapse CD19, same real LBCL cohort (the fairer test)

This is the clinically meaningful version: does a distribution-aware view of the SAME cohort's real antigen-density drop (5,810 → 2,021 molecules/cell) tell a different story than just watching the mean fall?

- At the single default kill_threshold (0.5), swept across all 4 real k_intra fits: **0 of 4 reordered** — an initial honest negative finding.
- Before trusting that as final, the check was broadened across a real, defensible kill_threshold range (0.1–0.9, the same discipline this project has always used to avoid narrowing scope prematurely on an unvalidated parameter): **2 of 36 grid points (5.6%) showed real reordering.** Example: at `blinatumomab_ifn_gamma` calibration, `kill_threshold=0.8`, the model predicts at-relapse (98.60% escape) as *marginally less escaped* than pre-treatment (98.82% escape) — the opposite of what the naive mean-density comparison would suggest, at that specific corner of the parameter space.

**Honest characterization of this finding:** this is a real, data-grounded reordering — the same class of result as the original EV project's Aim 9 (which found reordering at 8.7% of its own plausibility grid). It is a *sensitivity/reordering finding*, not a validated clinical prediction: 5.6% is a real but modest fraction, found at a specific, somewhat extreme threshold regime (kill_threshold=0.8, meaning a very strict definition of "reliably killed"), and the underlying data is two summary-statistic snapshots (median/IQR), not raw single-cell measurements. This should be reported with the same precision Aim 9's own "SCOPE REMINDER" insists on: a real reordering finding on real data, not a claim that the model has been validated against clinical outcome.

### AND-gate dual-antigen extension

Built and tested (reusing Aim 5's independent-draw AND-logic convention): confirmed the basic physical sanity property that an AND-gate's escape fraction never exceeds either single marker's own escape fraction alone. No real joint (two-antigen, same-cell) dataset was available to run a genuine dual-antigen ranking comparison — this mirrors the original EV project's own honest data gap for its AND-gate work (Aim 5's own stated limitation), not a new problem introduced by the pivot.

## The honest ceiling (state this plainly in any write-up)

This work does **not** address CAR-T's other major failure modes: T-cell exhaustion, trafficking/infiltration into solid tumors, or the immunosuppressive tumor microenvironment. The claim is narrowly "a distribution-aware method for prioritizing which target antigen to build a therapy around, given its real population-level density distribution" — not "solves antigen escape" or "cures CAR-T's limitations." This is the same honesty standard the original EV project held itself to throughout (see `EV-Capture-CURRENT.md`'s "Known risks" section for the precedent).

The superselectivity-to-immunology crossover remains genuinely novel (the pivot document's own research found this at opinion/commentary level in the literature, not an established sub-literature) — a real strength (novelty) that also means less existing work to lean on for validation conventions.

## Aim 12: the real single-cell (CyTOF) reordering check

### Why this check exists

Aim 11's ranking check used tumor antigen-density populations RECONSTRUCTED from published summary statistics (a median + IQR, or a positivity fraction + range) — never a population built from actual individually-measured per-cell values. The same was true, in different clothing, of the original EV project's Aim 9: even its "raw data" check only ever used a real per-vesicle BINARY presence/absence call to derive one positivity rate, then built a synthetic population around that single number. This raised a real, previously-untested question: was the small reordering effect (5.6%-17.8% across every check so far) a property of the biology/model, or an artifact of always testing a reconstructed distribution instead of a genuinely measured one?

### The real data

A public dataset was found and directly verified: Weng lab (BC Cancer Agency / UBC), "Mass Cytometry of Diffuse Large B-Cell Lymphoma (CyTOF cohort)," Mendeley Data, DOI 10.17632/rstwmcw94x.1 (published Oct 2025, CC BY 4.0) — 41 real DLBCL tumor samples run on a real CyTOF2 mass cytometer with a real 40-antibody B-cell panel, stored as standard per-sample FCS3.0 files. CD19 (parameter #19, tag "142Nd-CD19") was directly confirmed present in the real panel by parsing two independent real files' own embedded metadata — not assumed from a paper's text. **All 41 of the 41 real tumor samples** were downloaded and parsed (an initial 9-sample subset was processed first for practicality, then the author explicitly asked to get and test the rest of the dataset, and every remaining sample was fetched and added), yielding **6,865,361 real individual cells'** worth of measured per-cell CD19 signal — the complete real cohort, not a subsample.

**A real parsing bug was caught and fixed while processing the full cohort:** several of the larger real files (e.g. `CytB3_DLB_Q5719.fcs`, 128.8 MB) turned out to have `data_start=0` and `data_end=0` in their fixed-width header — not corruption, but the FCS3.0 spec's documented fallback for files whose real DATA segment offset (here, 128,803,120) needs more digits than the header's fixed 8-character field allows. The spec's fallback stores the real offsets in the TEXT segment itself as `$BEGINDATA`/`$ENDDATA`. This was diagnosed directly against the real failing file (not assumed from the spec alone), fixed in `parse_fcs3_text_segment()`, and covered by two new dedicated tests.

**How the data was actually obtained, stated plainly:** this project's sandboxed execution environment has no general network access (verified directly: a plain network request to the dataset's host, and separately to google.com, both failed outright). The real FCS files were fetched and parsed inside a real web browser session instead (using the browser's native fetch plus a hand-written binary FCS3.0 parser), and the resulting per-cell arrays were summarized inside that browser session before being reported back. `aim12_single_cell_cytof_reordering.py` contains a full, independently tested, general-purpose FCS3.0 parser (verified against real dataset structural facts, and against a from-scratch synthetic FCS file byte-for-byte in the test suite) so this result is fully reproducible by anyone with normal internet access and the real public files saved locally — this session's own limitation was environmental, not methodological.

### What was found — full 41-patient cohort

Using the 3 real k_intra fits from Aim 10 (CLN-978_cytolysis, blinatumomab_cytolysis, blinatumomab_ifn_gamma) swept across kill_threshold 0.1-0.9 (the same 27-point-grid convention as Aim 11), and the naive mean-density ranking of all 41 real patients as the baseline:

- **Reordered by any amount: 27/27 (100%).** This number alone is misleading — it includes trivial reorderings inside the model's saturation zone, where every patient's escape fraction is already pinned near 0% or 100% and a biologically meaningless microscopic difference can still flip an ordinal ranking (the same artifact this project already caught and named in Aim 11's blinatumomab_ifn_gamma checks).
- **Reordered with a MEANINGFUL spread (≥2 percentage points of real escape-fraction difference between the reordered patients): 16/27 (59.3%).** This is the honest, non-inflated number, and it is roughly 7-11x larger than every reconstructed-distribution check this project has run (Aim 9: 8.7%; Aim 11: 5.6% narrow / 17.8% broad sweep).
- **Largest single real spread observed: 81.8 percentage points** (one real patient's predicted escape fraction 81.8 points higher than another's, at the CLN-978_cytolysis calibration, kill_threshold=0.3) — nearly the entire possible range, a genuinely large and clinically-relevant-looking magnitude.
- **Concrete example** (CLN-978_cytolysis, kill_threshold=0.5): the naive top-5-by-mean is O6357 > Q7998 > Q5971 > O8155 > Q7915. The model's top-5-by-escape-fraction is O6357 > Q5971 > O8155 > Q7998 > P7676 — P7676 (mean=109.1, ranked only 6th by naive mean) enters the model's real top 5, displacing Q7915 (mean=111.8, a HIGHER mean than P7676) which drops out once the full per-cell distribution shape is used instead of just the average. This is exactly the mean-vs-distribution-shape distinction the superselectivity model exists to detect, now visible across the complete real cohort.

**Critically, this result is stronger than the initial 9-patient subsample, not weaker or the same** (48.1% meaningful reordering / 59.4pp largest spread on 9 patients, vs. 59.3% / 81.8pp on all 41). This is the direction a real, biology-grounded signal should move as more real data is added — a data-selection artifact or a lucky subsample would be expected to regress toward the smaller reconstructed-distribution numbers (5.6%-17.8%) as sample size grew, not move further away from them.

### Honest limitations of this specific finding — read before treating it as conclusive

1. **No clinical outcome data attached — actively searched for, the abstract itself obtained and read, and still not usable.** The public dataset's own clinical finding concerns T-cell subsets (CD57+ terminally differentiated T-cells predicting outcome), not B-cell/tumor CD19 density — no outcome-linked grouping variable for CD19 was confirmed to exist in the public files. A dedicated literature search (PubMed, full pagination of all 59 Weng-lab lymphoma papers, plus targeted phrase and co-author searches) found no full peer-reviewed journal paper linking patient-level outcome/relapse/survival data to these specific 41 sample IDs. The likely companion work — the 2021 ASH Blood conference abstract, "Immune Profiling of Diagnostic DLBCL Biopsies Dramatically Improves upon Cell-of-Origin Risk Stratification" (Nissen, Wang, Sarkozy, Jiang, ... Weng) — was never indexed in PubMed as a full journal article, and its full text was blocked by bot-detection on ashpublications.org and sciencedirect.com; however, the user separately obtained and provided its full abstract text and sole figure. Reading it directly (rather than inferring from the title) confirms two things precisely: (a) its CyTOF/discovery cohort is **54 DLBCL cases**, not 41 — a real, unresolved size mismatch with the Mendeley dataset's 41 samples that should NOT be assumed to be "the same cohort, just filtered down" without independent confirmation (it could equally be an overlapping-but-distinct set, or two separate biobank draws from the same lab); (b) even if the cohorts do turn out to be identical, the abstract's actual outcome classifier is ABC-DLBCL subtype **combined with** a T-cell-microenvironment phenotype (CD57+ terminally differentiated T-cell dominance) — it is a T-cell classifier layered on COO subtype, not a CD19/B-cell density classifier, and the abstract's own text states traditional exhaustion markers (PD-1, TIM3, LAG3, TIGIT) were explicitly NOT predictive, underscoring that this is a distinct biological axis from tumor antigen density. The abstract's single figure is a generic cohort/pipeline schematic (patients → CyTOF or flow cytometry → phenotype clustering → Kaplan-Meier survival by ABC/CD57 group) with no per-patient data table and no fields linkable to the Mendeley sample IDs (P5904, Q7998, etc.). The closest confirmed-accessible predecessor paper, Nissen et al. 2019 (Cytometry Part A, DOI 10.1002/cyto.a.23919, PMID 31637838), remains a smaller (n=27), earlier, differently-conclusioned pilot from the same group. Bottom line: even with the abstract in hand, this remains a real reordering-effect finding, NOT a validated outcome prediction — the gap is now precisely characterized (cohort-size mismatch + wrong biological axis) rather than just "not found."
2. **CyTOF signal is not confirmed to be absolutely molecule-calibrated.** Unlike Aim 10's IndEx-2 data (which used Quantibrite PE calibration beads for a true molecules-per-cell measurement), this dataset's raw ion-count signal was not confirmed this session to include an equivalent bead-based absolute calibration step. The real k_intra thresholds from Aim 10 (81, 843, 8,690) are being applied to a same-order-of-magnitude but not confirmed-identical-unit scale. This finding should be read as a genuine test of the model's SHAPE-sensitivity to real distributional heterogeneity, not as an absolutely-calibrated clinical prediction.
3. **Single antigen, single disease.** This is CD19 in DLBCL only — it does not by itself establish the framework generalizes to other antigens or cancers (see the project's own broader "is this generalizable" open question).
4. **Only the B-cell (tumor) panel's DLBCL samples were used** — the 31 real RLN (non-tumor) control samples and the parallel T-cell-panel files in the same dataset were deliberately not processed (out of scope for a tumor-antigen target-selection question), not an oversight.

### Why this finding changes the honest assessment of the project

Every prior check in this project — EV and CAR-T alike — used a population reconstructed from summary statistics, and every one of them found a small (5.6%-8.7%) reordering effect. This raised a real, fair concern: maybe the reconstruction step itself was smoothing away exactly the kind of distributional heterogeneity the model's whole premise depends on, meaning the small effect size said more about the synthetic-reconstruction method than about the biology. Aim 12 is the first direct test of that concern, and it resolves it in the more interesting direction: real, individually-measured single-cell data across the complete real 41-patient cohort shows a substantially larger effect (59.3% meaningful reordering, with individual spreads up to 81.8 percentage points) than any reconstructed population ever did — and this effect got LARGER, not smaller, when the sample grew from an initial 9-patient subset to the full 41. This does not yet prove the framework is clinically validated (see limitations above) — but it is real, new evidence that the small effect sizes found everywhere else in this project were, at least in part, an artifact of the data-reconstruction method, not a ceiling on what the underlying model can detect.

## What remains open (real, stated gaps — not silently dropped)

- Aim 12 now uses genuine single-cell (CyTOF) data with real per-cell CD19 density across the complete real 41-patient cohort, resolving the original EV project's own long-standing "no real single-cell dataset with per-cell antigen density" gap for this specific question. What it still lacks: a real tumor/outcome grouping variable linked to these same 41 patients. This was actively searched for (see limitation #1 above), and the likely companion abstract's full text was eventually obtained (by the user, directly) and read carefully. Two precise, honest findings resulted, neither of which closes the gap: **(a) a cohort-size mismatch** — the abstract's CyTOF/discovery cohort is 54 DLBCL cases, not 41, and this project has not independently confirmed whether the 41-sample Mendeley release is a filtered subset of those 54, an overlapping-but-distinct set, or a separate cohort from the same lab; **(b) an axis mismatch** — even setting (a) aside, the abstract's actual outcome classifier combines ABC-DLBCL subtype with a CD57+ terminally-differentiated-T-cell-dominant microenvironment, which is a T-cell phenotype axis, not tumor-cell CD19 density, and its one figure is a generic pipeline/survival-curve schematic with no per-patient data linkable to the Mendeley sample IDs. Remaining avenues not yet exhausted: contacting the dataset's corresponding author directly to ask about the 54-vs-41 discrepancy and whether any CD19-linked outcome variable exists, or checking bioRxiv/medRxiv preprints (not covered by PubMed). If outcome data for this same cohort is ever obtained AND the cohort-identity question is resolved, the reordering finding could be upgraded from "a real distributional-sensitivity effect" to "a real predictor of who actually relapses" — but both of those are still open conditions, not one.
- The kill-response curve calibration (Aim 10) is a one-point fit per real threshold, not a multi-point least-squares fit to a full continuous dose-response curve (the source app note reports threshold crossings via ROC analysis, not the full underlying curve with per-point data). A future session with access to the full Figure 5 data could upgrade this.
- The CyTOF signal used in Aim 12 is not confirmed to be absolutely molecule-calibrated (see Aim 12's own limitations) — a future session could look for the dataset's own bead-based calibration data (if any) or an independent calibration source to convert it to true molecules-per-cell, making it directly comparable in absolute terms to Aim 10's IndEx-2 thresholds.
- No real joint two-antigen dataset exists yet for a genuine AND-gate ranking comparison (same gap as the original EV project's Aim 5).
