## Question 2 first: what "multi-marker" work already existed, and what it didn't cover

The user's memory of a multi-target/selectivity-amplification idea traced back to the v5 handoff ("Multi-marker capture is a core sub-aim, not a footnote"), which became `aim3b_cooccurrence_model.py` two sessions ago. Checking that file's actual functions directly (not trusting the "multi-marker" label alone) showed it answers an **OR-gate yield question**: if you capture on EITHER of two markers, how much more total yield do you get versus your best single marker? (Real answer, from Mizenko's data: modestly more, 1.02x-1.26x depending on an unconstrained parameter — well below the project's original informal 2-4x hope.)

It does **not** answer an **AND-gate selectivity question**: if you require BOTH markers simultaneously, does that sharpen the tumor-vs-normal *selectivity ratio* — a mechanistically distinct question, since an AND-gate can suppress off-target capture much more than on-target capture if the two populations differ more on their joint distribution than on either marginal. A direct code search (`grep -n "AND.gate\|joint.*capture.*probab" src/*.py`) confirmed zero existing code for this. This is a real gap, not something quietly built and forgotten.

## The AND-gate model itself: `src/aim5_and_gate_dual_marker_selectivity.py`

**The honest data problem, stated up front (mirroring Aim 3b's own honesty about Mizenko):** Lennon et al.'s real digitized data has real per-vesicle EGFR counts and real per-vesicle CA19-9 counts for the same two populations (healthy plasma, PDAC plasma) — but NOT both markers measured on the same individual vesicle (they come from two separate scatter-plot panels). So a true joint AND-gate can't be built from directly-measured joint data. Handled the same way Aim 3b handled the analogous Mizenko gap: built a joint reconstruction (via a Gaussian copula) anchored to the two REAL marginal distributions (real means, taken directly from the real digitized data, at a standard negative-binomial dispersion), with an EXPLICIT, swept correlation parameter rather than a silently-assumed independence.

**The physical model, stated explicitly:** an AND-gate capture surface co-immobilizes both antibody types; a vesicle is captured only if it would independently be captured through EACH marker's own `capture_probability_patch()` — i.e. `theta_AND = theta_EGFR × theta_CA199`. This is the simpler of two possible physical models (a true shared multivalent bond-counting process across both marker types is a bigger physics change, left as a named, unbuilt future extension).

**A real bug caught before trusting any result:** the first version of `single_marker_yield()` computed `k_geom` separately for each population from its own mean, silently introducing a second free parameter that partially canceled the real tumor/normal difference — this produced a CA19-9-only ratio of ~1.04, sharply disagreeing with the project's own already-established headline number (1.4373, from `aim3_aim4_range_sweep.sweep_ranking_flip_robustness()`). Caught by comparing the new module's number against that existing, independently-verified reference before trusting it — exactly the project's standing "verify against real code/data before trusting any output" discipline. Fixed by anchoring `k_geom` once to the healthy population's mean and reusing that same value for both populations, matching `sweep_ranking_flip_robustness()`'s own documented convention exactly. After the fix, the CA19-9-only ratio matches the reference to machine precision.

**A second real numerical issue caught and diagnosed, not just patched:** at very dilute z (the same regime this project's own superselectivity finding lives in) combined with high assumed marker correlation, the AND-gate ratio swung wildly across random seeds (67 to 99 at z=1e-4, correlation=0.9, n_vesicles=50,000) — a genuine Monte Carlo rare-tail sampling instability (the population mean was being driven by a tiny fraction of extreme synthetic vesicles), not a transient fluke (confirmed: it didn't converge even at 500,000 samples). Rather than picking a bigger sample size and hoping, built an explicit reliability diagnostic (`top_1pct_contribution`, flagging any cell where the top 1% of simulated vesicles drives more than half the population mean) that correctly flags this exact regime as unreliable and correctly passes the stable z=1.0 default regime — the same "make numerical unreliability explicit and reported, not silently absorbed" discipline this project's `MIN_RELIABLE_EXPONENT_AT_N1` guard already applies for a different reason (floating-point precision vs. Monte Carlo sampling noise here).

## The finding

At the project's default, checked-stable regime (z=1.0, the same default `sweep_ranking_flip_robustness()` uses), the AND-gate selectivity ratio **exceeds the best single-marker ratio (CA19-9 alone, 1.4373) at every one of the 8 k_intra values in the real-sigma plausibility range, across every tested correlation from 0 (independence) up to 0.8** — reliability-diagnostic-confirmed at every one of these cells, not just numerically plausible-looking. At independence (correlation=0), the AND-gate ratio is 1.5505 at the headline k_intra; it decays gracefully (but stays above the single-marker baseline) as assumed correlation increases, which is physically sensible — more-correlated markers carry less independent discriminating information. This is a real, new, checked finding: requiring both EGFR and CA19-9 for capture would, under this model and this real digitized data, sharpen tumor-vs-normal selectivity beyond either marker alone, across the entire plausible parameter range this project already uses everywhere else.

## What this closes, and what's still open

This answers the user's specific question ("did we ever look into multi-target selectivity amplification") with a real, checked, positive result, and gives the project a second independent computational contribution alongside the CA19-9 ranking-flip case — potentially strengthening the novelty case discussed above (an AND-gate strategy for EV capture selectivity is a real, if separately-established, idea in the literature; combining it with this project's own joint per-EV distribution framework, on real digitized data, has not been shown to exist elsewhere as far as searched).

**What remains open, stated honestly:**
- The correlation parameter is assumed IDENTICAL for tumor and normal populations — a simplifying assumption, not tested for sensitivity to being wrong (a further, unbuilt axis).
- The "two independent binding events" physical model is the simpler of two plausible AND-gate physical models; a true shared multivalent bond-counting process across both marker types is unbuilt.
- No real joint (EGFR, CA19-9) per-vesicle measurement exists to check the copula reconstruction against — same honest data gap Aim 3b already carries for Mizenko's markers.
- The dilute-z/high-correlation regime is confirmed numerically unreliable; this finding is reported only for the checked-stable z=1.0 regime, matching the project's other range-sweep defaults.
