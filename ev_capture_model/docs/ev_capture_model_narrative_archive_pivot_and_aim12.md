## The pivot decision and its reasoning

A separate research pass (`PIVOT-FOR-NOVELTY.md`, done in a prior session at Dylan's and his parents' explicit request to increase the project's real-world impact ceiling) found that early cancer detection from blood is biologically bottlenecked — very little tumor material reaches the blood at an early stage, so no amount of clever marker-selection math can move the needle much, a fact the project's own MASEV validation already illustrates honestly (single-tetraspanin purification loses up to 80% of KRAS-mutant EVs, yet the real-world early-detection gain stays small because shedding, not marker choice, is rate-limiting).

CAR-T target-antigen selection was identified as the strongest available pivot: it reuses ~70% of the project's existing machinery (the nonlinear capture/binding model, the superselectivity/alpha framework, the AND-gate dual-marker logic) almost one-to-one, targets a genuinely open, confirmed gap (no existing tool convolves a tumor's real per-cell antigen-density distribution with the nonlinear CAR-T kill-response curve to predict escape fraction and rank targets — current tools use binary positivity or average expression), and has a larger real-world lever: CAR-T target selection is a decision made once, up front, when a therapy is designed, so a better method could mean fewer patients relapse from antigen escape. This gap was independently re-verified via fresh search before building anything (not assumed to still hold from the prior session's research) — confirmed still open as of August 2026, and re-confirmed again in the impact/competitiveness assessment session (see `EV-Capture-CURRENT.md`'s current "Known risks" for that later re-check).

## Aims 10-11: build and calibration

Two new modules were built: `src/aim10_car_t_kill_probability_model.py` (the kill-probability model, a relabeled reuse of `binding_model.capture_probability()`, with a REAL one-point calibration against real titrated CD19 dose-response data — Agilent/Antibody Analytics IndEx-2 application note, June 2024) and `src/aim11_antigen_target_ranking.py` (the ranking comparison: naive mean-density ranking vs. distribution-aware escape-fraction ranking, on real published LBCL and myeloma CD19 summary statistics).

Three real implementation bugs were caught and fixed during this work, each directly by running the code end-to-end: (1) a float64 overflow/NaN in the kill-curve calibration's root-finding bracket, requiring three iterations to get the derivation actually right; (2) the EV project's own existing negative-binomial fitting function failing at this pivot's input scale, requiring a new, independently-verified fitting function rather than forcing the reused one; (3) a real 120+-second timeout from redundant re-fitting across a grid sweep, fixed via caching.

Real finding: an initial check at a single default threshold found no reordering (a weak/negative result, reported honestly); broadening the sweep across a real, defensible kill_threshold range found genuine reordering at 5.6% of a 36-point grid. 13 new tests added (7 for Aim 10, 6 for Aim 11).

## Aim 12: the single-cell CyTOF check, full story

Aim 11's ranking check used tumor antigen-density populations RECONSTRUCTED from published summary statistics — never a population built from actual individually-measured per-cell values. This raised a real, previously-untested question: was the small reordering effect (5.6%-17.8% across every check so far) a property of the biology/model, or an artifact of always testing a reconstructed distribution instead of a genuinely measured one?

A public dataset was found and directly verified: Weng lab (BC Cancer Agency / UBC), "Mass Cytometry of Diffuse Large B-Cell Lymphoma (CyTOF cohort)," Mendeley Data, DOI 10.17632/rstwmcw94x.1 (published Oct 2025, CC BY 4.0) — 41 real DLBCL tumor samples run on a real CyTOF2 mass cytometer with a real 40-antibody B-cell panel, stored as standard per-sample FCS3.0 files. CD19 (parameter #19, tag "142Nd-CD19") was directly confirmed present by parsing two independent real files' own embedded metadata.

**Two real parsing bugs were caught and fixed:**
1. `extract_parameter_values()` originally only checked the DATA segment's claimed size for internal consistency with the file's own header, not against the actual physical byte length of the file/buffer — a truncated/corrupted file could pass its own consistency check while still being unsafe to read from. Fixed by adding a direct check against `len(raw_bytes)`.
2. Several large real files (e.g. `CytB3_DLB_Q5719.fcs`, 128.8 MB) turned out to have `data_start=0` and `data_end=0` in their fixed-width header — not corruption, but the FCS3.0 spec's documented fallback for files whose real DATA segment offset (here, 128,803,120) needs more digits than the header's fixed 8-character field allows. The spec's fallback stores the real offsets in the TEXT segment itself as `$BEGINDATA`/`$ENDDATA`. Diagnosed directly against the real failing file, fixed in `parse_fcs3_text_segment()`, covered by two new dedicated tests.

**How the data was actually obtained:** this project's sandboxed execution environment has no general network access (verified directly). The real FCS files were fetched and parsed inside a real web browser session instead (using the browser's native fetch plus a hand-written binary FCS3.0 parser), with per-cell arrays summarized inside that browser session before being reported back (the browser-to-sandbox transfer channel truncates around ~1500 characters, so raw arrays could never leave the browser — only small JSON summaries). A fire-and-forget async pattern (`window.__pendingResult`, polled across calls) was needed to survive a 45-second per-call timeout on the larger files. `aim12_single_cell_cytof_reordering.py` contains a full, independently tested, general-purpose FCS3.0 parser so this result is fully reproducible by anyone with normal internet access and the real public files saved locally.

**Result, initial 9-patient subset:** 48.1% meaningful reordering, largest spread 59.4 percentage points.

**Result, full 41-patient cohort (6,865,361 real cells total):** 59.3% meaningful reordering (16/27 grid points), largest single spread 81.8 percentage points — roughly 7-11x larger than every reconstructed-distribution check the project has run (Aim 9: 8.7%; Aim 11: 5.6% narrow / 17.8% broad). Concrete example (CLN-978_cytolysis, kill_threshold=0.5): naive top-5-by-mean is O6357 > Q7998 > Q5971 > O8155 > Q7915; the model's top-5-by-escape-fraction is O6357 > Q5971 > O8155 > Q7998 > P7676 — P7676 (mean=109.1, ranked 6th by naive mean) enters the real top 5, displacing Q7915 (mean=111.8, a HIGHER mean) which drops out.

**Critically, the result got stronger, not weaker, moving from 9 to 41 patients** — the direction a real, biology-grounded signal should move, not what a data-selection artifact or lucky subsample would do.

11 new tests, all passing. Full project suite: 173/173.

## Why the effect is so much larger than every reconstructed-distribution check (the mechanistic explanation given to Dylan)

Every earlier check in the project (EV data, reconstructed CAR-T populations) started from just one or two summary numbers per sample and built a synthetic population using a negative-binomial formula matched to those numbers. That formula can only match the 1-2 numbers fed to it — it cannot know whether the real population clusters tightly around its mean or has a long tail of high-expressing outliers, since both can produce an identical mean.

Direct comparison of mean vs. median across the 41 real CyTOF patients shows enormous, patient-specific shape variation the reconstruction method cannot see: mean/median ratios range from 1.08x (Q5971, tightly clustered) to 29.78x (R5097, heavily right-skewed) — a 27.5x range in skewness across real patients — and the fraction of near-zero cells ranges from 0.28% (Q5971) to 21.68% (R7381), a 77x range. Since the superselectivity model's whole premise is that kill probability depends nonlinearly on each individual cell's own receptor count (not the population average), feeding it real shape-diverse data is exactly the condition where it should show its largest effect — and that is what happened. The fact that the effect grew, not shrank, from 9 to 41 patients is additional evidence this is a real signal rather than a lucky small sample.

## The outcome-data search (exhaustive, documented)

A dedicated PubMed search (full pagination of all 59 Weng-lab lymphoma papers, plus targeted phrase and co-author searches, run via a subagent to keep the raw search noise out of the main session) found no full peer-reviewed journal paper linking patient-level outcome/relapse/survival data to the 41 Mendeley sample IDs. The likely companion work, a 2021 ASH Blood conference abstract ("Immune Profiling of Diagnostic DLBCL Biopsies Dramatically Improves upon Cell-of-Origin Risk Stratification," Nissen, Wang, Sarkozy, Jiang, ... Weng), was never indexed in PubMed as a full journal article, and its page was blocked by bot-detection on both ashpublications.org and sciencedirect.com (not bypassed, per this project's standing instruction-source-boundary discipline).

Dylan separately obtained the abstract's full text and sole figure directly and provided them. Reading them revealed two precise, still-open problems rather than a resolution: (1) the abstract's CyTOF/discovery cohort is 54 DLBCL cases, not 41 — an unresolved, unconfirmed size mismatch with the Mendeley release; (2) even setting that aside, the abstract's actual outcome classifier is ABC-DLBCL subtype combined with a CD57+ terminally-differentiated-T-cell-dominant microenvironment — a T-cell phenotype axis, not tumor CD19 density — and its one figure is a generic pipeline/Kaplan-Meier schematic with no per-patient data linkable to the Mendeley sample IDs. See `docs/CAR_T_Pivot_Validation_and_Findings.md`'s limitation #1 for the current, precise statement of this gap.

## The honest impact/novelty/competitiveness assessment (delivered, not softened)

At Dylan's request, a full assessment was produced after Aim 12's full-cohort result and the outcome-data search concluded. Verified independently (re-ran the full test suite directly — 173/173 — rather than trusting the doc's self-report; checked current 2025-2026 CAR-T target-selection literature to confirm the novelty claim still holds, rather than relying on memory).

**Impact: 40/100.** Real mechanism, real gap in the field (current tools rank targets by bulk/mean expression, not per-cell distribution shape), but zero clinical-outcome evidence anywhere in the project, and a real deployment would need prospective validation this project cannot obtain.

**ISEF competitiveness: 78/100.** Strong on the two things fresh ISEF-winner research found actually separates winners: validation against real, independent data at multiple tiers of directness (summary stats → raw per-vesicle → full single-cell cohort), and genuinely new, previously-unstated claims (Aim 9, Aim 11, Aim 12's reordering findings) rather than reproductions. Strong process discipline (a prediction registry with honestly-reported non-clean-wins, real bugs caught and documented rather than hidden). Held back from higher by the total absence of outcome-linked validation, and by narrative complexity from the pivot itself.

**Weak points judged genuinely unfixable, with the specific reason checked for each:** (1) no public clinical outcome data exists for the 41-patient cohort, reachable independently by a high schooler before a Feb/March fair — confirmed via exhaustive search, not assumed; (2) the underlying superselectivity physics is an established field, not Dylan's invention — permanently true, but fine, since the contribution is the application; (3) the CyTOF signal's absolute molecule-per-cell calibration is not confirmed matched to the CD19 dose-response calibration data's units, and no public source ties this specific instrument run to an absolute standard.

**Weak points judged fixable, with a plan and odds:** (1) outcome-linkage gap — email the corresponding author or find a different dataset; odds ~20/100 in the given timeframe. (2) CyTOF absolute calibration — search for the dataset's own bead-calibration metadata or an independent calibration curve for the same antibody/tag; odds ~45/100 (a real, not-yet-exhausted search). (3) EV-side K_INTRA/z calibration — six dedicated sessions already failed; odds ~10/100 of a new approach succeeding. (4) write-up/poster assembly — pure execution, odds ~90/100. (5) generalizing the CD19/DLBCL finding to a second antigen/disease pair — odds ~35/100, limited by the rarity of usable single-cell antigen-density datasets (this project's own multi-session search history is the evidence for that rarity).
