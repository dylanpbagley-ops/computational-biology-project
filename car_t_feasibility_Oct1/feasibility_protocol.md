# CAR-T data feasibility investigation

Recorded before calculating any new predictive performance on the candidate datasets.

Scope: inspect accessible primary data for construct-specific sustained CAR-T performance. Specialized lab access is not an assumed resource. Preserve the historical project and locked predictions.

Primary candidates: Barisa et al., Nature Communications 2025, DOI 10.1038/s41467-025-61427-4; Majzner et al., Cancer Discovery 2020, DOI 10.1158/2159-8290.CD-19-0945; Shah et al., AML functional modeling, linked repository DOI 10.5281/zenodo.12823159.

Acceptance questions: are files actually accessible; do they contain measured antigen distributions rather than only means; are units calibrated; are killing and expansion measured in compatible experiments; are donor/run identifiers available; can independent functional evaluation be performed; what has the original study already established?

Reproduction, if attempted, is explicitly a discovery-data feasibility check. No candidate read during selection becomes a blinded prospective test. Any exploratory fits or calculations must be reported as exploratory; no model selection or tuning on claimed validation outcomes. Biological replication, not cell count or technical wells, determines independence.

Outputs: downloaded source files and provenance; file-level inventory; one appropriate numerical reproduction if the data permit; competing-method comparison; go/narrow/stop recommendation. Failure to obtain full single-cell distributions is a substantive limitation, not permission to invent them from averages.
